# Lumen

Player IPTV para listas **Xtream Codes**: canais ao vivo com guia, filmes e séries numa interface
de streaming. Android (celular e TV box), Windows e Linux.

## Baixar

Pegue a versão mais nova em [Releases](https://github.com/jesieldotdev/lumen/releases/latest):

| Aparelho | Arquivo |
| --- | --- |
| Celular Android (Android 9+) | `Lumen-arm64-v8a.apk` |
| TV box / Android TV 32 bits | `Lumen-armeabi-v7a.apk` (se o de 64 bits não instalar) |
| Windows 10+ | `Lumen-windows-x64.zip` (descompacte e abra `Lumen.exe`) |
| Linux x86_64 | `Lumen-x86_64.AppImage` (`chmod +x` e abra) |

## Aviso

O Lumen é só o player. Ele não vende, não inclui e não indica canais, filmes ou listas: você usa o
servidor, o usuário e a senha da assinatura IPTV que já tem, de um provedor autorizado a distribuir
o conteúdo.

Este repositório guarda apenas os instaladores.
